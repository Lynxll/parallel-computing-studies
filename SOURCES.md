# Источники и ревизии

Этот репозиторий содержит две задачи из авторских веток общих учебных репозиториев. Исходники, тесты, настройки и исторические отчёты задач перенесены без изменений. README и этот указатель добавлены для навигации и описания известных ограничений.

Поэтому инструкция сборки закрепляет полный авторский fork/HEAD как окружение, а не утверждает эквивалентность чистой upstream-базы.

## Границы воспроизводимости

Сведения получены из локальных Git remote и refs при подготовке публикации. Они не утверждают, что upstream/master всё ещё указывает на эти commits. Удалённое наличие закреплённых ревизий и новая сборка не проверялись.

Для выбранных каталогов локальный Git status не показывал изменений. Публикуется файловый снимок задач; история общих репозиториев и чужие работы не переносятся.
